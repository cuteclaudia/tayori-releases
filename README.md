<h1 align="center">便り Tayori</h1>
<p align="center"><i>Mail, calendar, contacts and tasks. Part of 工房 Kōbō, by CuteClaudia.</i></p>

Tayori is CuteClaudia's mail program for **Windows and Linux**. It works with ordinary mail
accounts (IMAP and SMTP) and with Outlook.com and Microsoft 365.

## Download

Get the latest version from **[Releases](https://github.com/cuteclaudia/tayori-releases/releases/latest)**.

| System | File |
|---|---|
| Windows 10/11 | `tayori-<version>-windows-x64-setup.exe` (installer) or `…-portable.zip` |
| Linux, any distro | `tayori-<version>-linux-x86_64.AppImage` |
| Debian, Ubuntu, Mint | `tayori-<version>-linux-x86_64.deb` |
| Fedora, openSUSE | `tayori-<version>-linux-x86_64.rpm` |

Each release lists SHA-256 checksums in `SHA256SUMS.txt`, so you can check your download.

## Privacy

Tayori talks only to your own mail servers, and to this page to see whether a new version is out
(only if you agree). There is no telemetry, no analytics and no account. Pictures inside an email
load only when you ask. Every release passes a security check first: known vulnerabilities, where
the code comes from, every connection the program can make, and a virus scan.

## Problems and ideas

Please [open an issue](https://github.com/cuteclaudia/tayori-releases/issues/new). Never include
passwords or real mail in a report.
